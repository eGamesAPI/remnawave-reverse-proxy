## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**, а так же на сервере, на котором будет установлена нода Remnawave.
:::

Введите эту команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[Если GitHub недоступен]
Запустите установщик с зеркала на jsDelivr:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Установка ноды

### Что делает установщик

1. **Проверяет сервер перед стартом**: нода ещё не установлена, порт 443 свободен.
2. **Спрашивает три вещи**: selfsteal-домен ноды (адрес из её карточки в панели), IP-адрес панели и Secret Key ноды, ключ вставляется многострочной вставкой и подтверждается.
3. **Выпускает сертификат** на домен ноды (через DNS API, ACME или ваш собственный) и настраивает автопродление.
4. **Разворачивает сервисы в `/opt/remnanode`**: контейнер ноды `remnanode` и nginx за Unix-сокетом, по той же схеме, что у панели: Xray владеет 443 и передаёт трафик nginx через сокет.
5. **Открывает порт 2222 в файрволе только для IP панели**: панель сможет подключаться к ноде, для остальных порт закрыт.
6. **Ставит маскировочный сайт**: случайный шаблон обычного веб-сайта на домен ноды.
7. **Запускает и проверяет**: обращается к `https://домен` до 5 раз с паузой 15 секунд, пока нода не ответит.
