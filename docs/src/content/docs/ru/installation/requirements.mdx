:::tip[Если железо слабее]
`Remnawave` может работать и на меньших мощностях, но это не рекомендуется: некоторые фоновые процессы прожорливы до ресурсов. `Remnawave Node` сама по себе нетребовательна, но Xray-core под нагрузкой может съедать много CPU и RAM.
:::

## Что нужно подготовить

- **Права root** на сервере и свежая установка системы: протестировано на виртуализации KVM.
- **Свободные порты 80 и 443**: их займут веб-сервер и Xray. Порт 2222 для ноды скрипт откроет в файрволе сам, только для панели.
- **Три домена или поддомена**: панель, страница подписки и маскировочный сайт (selfsteal). A-запись новой ноды скрипт умеет создавать сам через API Cloudflare, Gcore или Bunny.net.

## Настройка доменов

Скрипт выпускает SSL-сертификаты двумя способами:

- **Cloudflare**: управление DNS через API, записи создаются сами по токену
- **ACME**: прямая интеграция с хостинг-провайдером, без API-ключа.

### Примеры конфигурации DNS

#### Установка на одном сервере (панель + нода вместе)

| Тип записи | Имя               | Значение         | Статус прокси |
|------------|-------------------|------------------|---------------|
| A          | example.com       | your_server_ip   | DNS only      |
| CNAME      | panel.example.com | example.com      | DNS only      |
| CNAME      | sub.example.com   | example.com      | DNS only      |
| CNAME      | node.example.com  | example.com      | DNS only      |

:::tip
Запись `node.example.com` необязательна для работы selfsteal: подойдёт и корневой домен `example.com`.
:::

#### Распределённая установка (панель и нода на разных серверах)

| Тип записи | Имя               | Значение                | Статус прокси |
|------------|-------------------|-------------------------|---------------|
| A          | example.com       | panel_server_ip         | DNS only      |
| CNAME      | panel.example.com | example.com             | DNS only      |
| CNAME      | sub.example.com   | example.com             | DNS only      |
| A          | node.example.com  | node_server_ip          | DNS only      |

## Когда всё готово

Запустите установщик на сервере под root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[Если GitHub недоступен]
Запустите установщик с зеркала на jsDelivr:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

После первой установки скрипт добавит себе короткий алиас `rr`: меню открывается командой `remnawave_reverse` или просто `rr`.
