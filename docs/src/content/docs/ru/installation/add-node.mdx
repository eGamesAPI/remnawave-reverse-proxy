## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**, а так же на сервере, на котором установлена панель Remnawave.
:::

Введите данную команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

## Добавить ноду в панель

Выберите пункт `Установка компонентов Remnawave`, затем `Добавить ноду в панель`.

![Main menu RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/main_menu.webp)

![Add node to panel RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/add_node_to_panel.webp)

После подтверждения, что вы на сервере панели, скрипт спросит, как настроить сервер ноды: `Автоматически по SSH` или `Вручную`. Для автоматического режима затем выбирается веб-сервер, nginx или Caddy. Дальше остаётся ввести домен ноды и её название, а разница только в том, кто будет ставить ноду на сервер.

## Автоматическая установка

Панель сама ставит ноду на её сервер: подключается по SSH, готовит машину и поднимает контейнеры. Заходить на сервер ноды не нужно.

**Что понадобится:**

- отдельный сервер с Debian или Ubuntu и root-доступом по SSH. Хватит пароля: скрипт поставит на сервер свой ключ, сам пароль нигде не сохранит и больше не спросит.
- домен ноды, например `node.example.com`.
- свободный порт 443 на сервере ноды. Для Caddy свободен должен быть и порт 80, правило файрвола скрипт добавит сам.

:::tip[Домен и DNS]
Если A-запись домена уже указывает на сервер ноды, установка пройдёт самым коротким путём. Если записи нет, скрипт создаст её сам через API вашего DNS-сервиса: Cloudflare, Gcore или Bunny.net, а недостающий ключ спросит один раз и запомнит. Можно и без API: скрипт покажет, какую запись добавить руками.
:::

**Как проходит установка:**

<Steps>

1. **Подключение по SSH.** Если доступ к этой машине уже настроен в разделе [SSH-доступ](/ru/configuration/ssh-remote-access/), он используется молча, без лишних вопросов. Для домена без A-записи скрипт спросит IP сервера, и это единственный дополнительный вопрос.

2. **DNS-запись.** Если записи ещё нет, скрипт создаст её сам. Зона, чей сертификат уже есть на панели, распознаётся автоматически. Для новой зоны скрипт спросит, каким DNS-сервисом пользоваться.

3. **Подготовка сервера.** Скрипт ставит пакеты и Docker с зеркалами на случай блокировок, поднимает ufw с открытым портом 443 и сохранённым SSH.

4. **Ключ связи и сертификат.** Сначала скрипт выпускает ключ связи ноды с панелью. Дальше сертификат: если wildcard панели уже покрывает домен ноды (`*.example.com` закрывает `node.example.com`), файлы копируются на ноду, а продления панель переносит туда сама. Если не покрывает, сертификат выпускается прямо на сервере ноды через DNS-проверку и продлевается там же, без участия панели. С Caddy всё проще: сертификат он выпускает и продлевает сам, панель в этом не участвует.

5. **Запуск.** Скрипт генерирует сайт-заглушку для маскировки, пишет конфигурацию и поднимает контейнеры ноды и выбранного веб-сервера.

6. **Проверка связи.** Скрипт ждёт, пока нода отчитается панели. Если DNS-запись совсем свежая и резолверы панели её ещё не видят, скрипт подскажет панели адрес напрямую, и подключение проходит сразу.

</Steps>

Когда появится сообщение `Сервер ноды настроен, нода работает`, установка закончена. Проверьте, что нода горит зелёным в разделе Nodes панели, а её домен открывает сайт-заглушку в браузере.

:::note[Замена существующей ноды]
Если на сервере уже работает контейнер ноды, скрипт обязательно переспросит перед заменой. Случайная переустановка исключена.
:::

:::note[Если что-то не получилось]
Нода в панели к этому моменту уже создана. Скрипт предложит повторить попытку, а если откажетесь, покажет, как завершить установку вручную.
:::

## Ручная установка

Скрипт создаст ноду, профиль и хост в панели, а установку на сервер вы выполните сами.

<Steps>

1. Введите ваш новый домен для `selfsteal` который будет использоваться для подключения ноды к панели, а так же название для самой ноды.

    :::danger[Важно]
    Не забудьте добавить DNS-запись для вашего домена.
    :::

    ![Add node to panel2 RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/add_node_to_panel2.webp)

2. После успешного добавления ноды в панель, запустите скрипт на вашем новом сервере, где будет установлена нода Remnawave, выберите пункт `Установка компонентов Remnawave`, а затем [`Установить только ноду`](https://wiki.egam.es/ru/installation/node-only/).

</Steps>
