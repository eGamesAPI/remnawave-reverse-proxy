## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**.
:::

Введите данную команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

## Установка панели и страницы подписки

Этот вариант устанавливает на один сервер панель, базу данных и страницу подписки (`remnawave/subscription-page`) — конфигурация, рекомендуемая официальной документацией Remnawave.

<Steps>

1. Выберите пункт `Установка компонентов Remnawave`

    ![Главное меню](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/main_menu.webp)

2. Затем выберите пункт `Установить панель и страницу подписки`

    ![Установить панель и страницу подписки](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/install_panel_sub.webp)

3. Выберите веб-сервер для панели. Скрипт полностью поддерживает оба варианта:

    - **Nginx** — классическая схема, которая использовалась во всех предыдущих версиях.
    - **Caddy** — автоматические HTTPS-сертификаты из коробки.

    ![Выберите веб-сервер](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/webserver_select.webp)

4. Введите три домена по запросу скрипта — панели, страницы подписки и selfsteal (подключение нод). Все три должны быть **уникальными**.

    :::tip
    Если A-запись домена ещё не указывает на сервер, скрипт предложит создать её автоматически через API **Cloudflare** или **Gcore** — либо вы создадите её вручную, и скрипт проверит запись ещё раз.
    :::

5. Выберите способ защиты панели:

    <Tabs>
      <TabItem label="Nginx" icon="seti:nginx">
        1. `Cookie-защита (по умолчанию)` — панель защищена секретной ссылкой, как в предыдущих версиях.
        2. `Страница входа (TinyAuth)` — дополнительная страница входа перед панелью. Скрипт сам развернёт [TinyAuth](https://tinyauth.com) и создаст пользователя.

        ![Способ защиты панели (nginx)](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/panel_auth_nginx.webp)
      </TabItem>
      <TabItem label="Caddy" icon="seti:caddy">
        1. `Cookie-защита (по умолчанию)` — панель защищена секретной ссылкой, как в предыдущих версиях.
        2. `Страница входа с MFA` — портал входа с многофакторной аутентификацией перед панелью.

        ![Способ защиты панели (caddy)](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/panel_auth_caddy.webp)

        :::note
        При включении портала с MFA настройте MFA для администратора после первого входа.
        :::
      </TabItem>
    </Tabs>

6. После завершения процесса скрипт предоставит все необходимые данные для входа в панель.

</Steps>

:::danger[Важно]
После завершения установки скрипт отобразит уникальный URL-адрес для входа в панель управления.  
**Обязательно сохраните этот URL-адрес.** Он содержит секретный ключ, необходимый для доступа.

Пример ссылки для входа:
```
https://p.example.com/auth/login?SECRET_KEY=SECRET_KEY
```
Без этого URL-адреса **вы не сможете** войти в панель (если только вы не включили страницу входа).
:::
