## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**.
:::

Введите эту команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[Если GitHub недоступен]
Запустите установщик с зеркала на jsDelivr:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Установка панели и страницы подписки

### Что делает установщик

1. **Проверяет сервер перед стартом**: панель ещё не установлена, порт 443 свободен.
2. **Спрашивает два домена**: панели и страницы подписки. Каждый проверяется на корректность и реальность DNS-записи, а домены должны быть разными.
3. **Готовит все секреты самостоятельно**: логин и пароль суперадмина, пару «имя=значение» для секретной ссылки входа, отдельную пару для метрики и `APP_SECRET`, всё будет показано в конце.
4. **Разворачивает сервисы в `/opt/remnawave`**: база PostgreSQL, кэш Valkey, панель Remnawave, обратный прокси и контейнер страницы подписки, который забирает конфигурации прямо у панели по API-токену.
5. **Выпускает сертификаты Let's Encrypt** на оба домена выбранным методом (DNS API, ACME HTTP-01 или ваш собственный) и настраивает автопродление.
6. **Настраивает панель через её API**: регистрирует суперадмина и выпускает токен для страницы подписки.
7. **Перезапускает всё начисто** (`down` + `up`), включая страницу подписки: если что-то не поднялось, ошибка не спрячется за зелёным баннером.
