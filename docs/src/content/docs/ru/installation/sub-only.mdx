## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**.
:::

Введите данную команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

## Установка только страницы подписки

Используйте этот вариант, если панель уже установлена на другом сервере, а страницу подписки (`remnawave/subscription-page`) вы хотите вынести на отдельный сервер — например, чтобы трафик пользователей не шёл через сервер панели.

:::note
Перед началом подготовьте **API-токен** в панели: `Настройки` → `API-токены`. Токену достаточно скоупов, которые использует страница подписки:

```
subscription-page-configs:list
subscription-page-configs:get
subscriptions:subpage-config
system:metadata
users:by-username
```
:::

<Steps>

1. Выберите пункт `Установка компонентов Remnawave`

    ![Главное меню](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/main_menu.webp)

2. Затем выберите пункт `Установить только страницу подписки`

    ![Установить только страницу подписки](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/install_sub.webp)

3. Выберите веб-сервер — **Nginx** или **Caddy**. Скрипт полностью поддерживает оба варианта.

    ![Выберите веб-сервер](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/webserver_select.webp)

4. По запросу скрипта введите:

    - **Домен подписки** — например, `sub.example.com`. Если A-запись ещё не указывает на сервер, скрипт предложит создать её автоматически через API Cloudflare или Gcore.
    - **Домен панели** — домен уже установленной панели, например, `panel.example.com`.
    - **API-токен панели** — токен, созданный на предыдущем шаге.
    - **Cookie панели** — пара `ИМЯ=ЗНАЧЕНИЕ` из ссылки входа в панель, например `zIdejKtN=MWbLrRzx` (та же пара, что в `auth/login?ИМЯ=ЗНАЧЕНИЕ`).

5. После завершения процесса страница подписки будет доступна на своём домене и подключена к вашей панели.

</Steps>
