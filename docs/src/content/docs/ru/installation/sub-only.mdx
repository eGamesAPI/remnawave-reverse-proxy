## Установка скрипта

:::danger[Важно]
Скрипт нужно запускать с **правами root**.
:::

Введите эту команду на вашем сервере:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[Если GitHub недоступен]
Запустите установщик с зеркала на jsDelivr:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Установка только страницы подписки

Используйте этот вариант, если панель уже установлена на другом сервере, а страницу подписки вы хотите вынести на отдельный сервер, например, чтобы трафик пользователей не шёл через сервер панели.

:::note
Перед началом подготовьте **API-токен** в панели: `Настройки` → `Токены API`
:::

### Что делает установщик

1. **Проверяет сервер перед стартом**: страница подписки ещё не установлена, порт 443 свободен.
2. **Спрашивает три вещи**: домен подписки (проверяется корректность и DNS-запись), домен уже установленной панели и API-токен панели.
3. **Узнаёт, чем защищена панель**: cookie, страницей входа TinyAuth или порталом Caddy, и просит соответствующий ключ: куку, логин с паролем или API-ключ.
4. **Выпускает сертификат** на домен подписки (через DNS API, ACME или ваш собственный) и настраивает автопродление.
5. **Разворачивает сервисы в `/opt/subscription`**: контейнер страницы подписки и веб-сервер перед ним. Файлы создаются с правами только для root.
6. **Запускает и проверяет**: обращается к `https://домен` до 5 раз с паузой 15 секунд, пока страница не ответит.
7. **Показывает финальный экран**: адрес страницы, напоминание прописать `SUB_PUBLIC_DOMAIN` в панели и предупреждение про совпадение cookie.
