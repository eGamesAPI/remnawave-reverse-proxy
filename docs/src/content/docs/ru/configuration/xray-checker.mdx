## Как это устроено

<XrayCheckerDiagram lang="ru" />

Подписку чекер получает одним из двух способов:

- **Служебный пользователь (рекомендуется).** Модуль создаёт в панели пользователя `xray-checker`, подключает его ко внутренним группам и берёт его подписку: новые ноды попадают в мониторинг сами, без перестройки.
- **URL вручную.** Подойдёт любая ссылка подписки `https://...`; при изменении набора нод адрес придётся обновлять самому.

:::note[Нестандартная страница подписки]
Авто-вариант ищет в compose панели сервис `remnawave-subscription-page`. Страница подписки, установленная не скриптом (например, [366-days](https://github.com/Mrvibecodic/366-days) by Mrvibecodic), тоже подходит: если её сервис назван так же, авто-подключение увидит её как обычную. При другом имени сервиса выбирайте «Указать URL подписки вручную».
:::

Каждый цикл чекер проходит прокси из подписки выбранным методом и пишет результат в метрики; статус-страница показывает историю, бот рассылает алерты.

:::note[Кэш страницы]
Статус-страница может стартовать дольше чекера. Установка не считается от этого проваленной: чекер отвечает на `127.0.0.1:2112`, а страница догонит через минуту-другую.
:::

## Что понадобится

:::danger[Важно]
Мониторинг устанавливается на отдельном сервере. Чекер проверяет ноды извне, как обычный пользователь, поэтому он сможет обнаружить и сбой самой ноды, и проблемы с дата-центром или сетью. На сервере с нодой метод «IP» работать не будет: выход через неё идёт с того же адреса.
:::

- Свободные порты `2112`, `8080` и `8081`.
- Docker: если его нет, модуль сам предложит установить серверные компоненты.
- Домен для публичной статус-страницы, например `status.example.com`. Без домена страница доступна только с сервера или по SSH-туннелю.

## Методы проверки

- **IP** (по умолчанию): лёгкий запрос через прокси, проверяется смена адреса выхода. Самый дешёвый способ, но только для чекера на отдельном сервере: рядом с нодой он вечно пометит её упавшей, и модуль сразу предупредит об этом.
- **HTTP-статус**: через прокси запрашивается страница и проверяется код ответа. Работает при любой раскладке серверов.
- **Скачивание**: качает тестовый файл около 1 МБ через каждый прокси каждый цикл. Самая честная проверка канала, но следите за трафиком.

При установке на сервере с нодой модуль отмечает «IP» предупреждением и рекомендует «HTTP-статус».
