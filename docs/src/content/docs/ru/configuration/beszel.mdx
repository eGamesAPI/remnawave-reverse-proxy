## Как это работает

<BeszelDiagram lang="ru" />

Браузер открывает веб-панель хаба по https. Агенты на нодах сами подключаются к хабу на порт 45876: хаб выдаёт им ключ при добавлении, и коннект инициирует именно агент, поэтому на ноде не нужно открывать ничего лишнего, кроме одного порта для IP хаба. Уведомления хаб отправляет вебхуком, например в Telegram.

:::note[Beszel не зависит от Remnawave]
Панель Remnawave не обязательна. С ней просто удобнее: wildcard-сертификат и реверс-прокси уже есть, останется добавить один блок конфигурации.
:::

:::note[Если ставите без панели]
Hub слушает `127.0.0.1:8090`, и есть два пути. С доменом: выпустите сертификат сами, например `certbot certonly -d beszel.example.com`, и поставьте любой реверс-прокси (nginx или Caddy): он примет https и передаст запросы на `127.0.0.1:8090`. Без домена: откройте панель через SSH-туннель, ничего не публикуя наружу:

```bash
ssh -L 8090:127.0.0.1:8090 root@your_server_ip
```

После этого панель доступна на `http://127.0.0.1:8090`.
:::

## Установка Beszel Hub

<Steps>

1. Создаём директорию для Beszel и открываем `docker-compose.yml`:

    ```bash
    mkdir /opt/beszel && cd /opt/beszel && nano docker-compose.yml
    ```

2. Добавляем сервис хаба:

    ```yaml title="docker-compose.yml"
    services:
      beszel:
        image: henrygd/beszel
        container_name: beszel
        restart: always
        ports:
          - '127.0.0.1:8090:8090'
        volumes:
          - ./beszel_data:/beszel_data
        logging:
          driver: 'json-file'
          options:
            max-size: '30m'
            max-file: '5'
    ```

3. Запускаем хаб:

    ```bash
    cd /opt/beszel && docker compose up -d && docker compose logs -f
    ```

4. Добавляем Beszel в веб-сервер, чтобы панель открывалась по своему домену:

    <Tabs>
    <TabItem label="Nginx">

    ```bash
    cd /opt/remnawave && nano nginx.conf
    ```

    :::danger[Важно]
    В примере используется wildcard-сертификат. Если у вас сертификат ACME, выпустите его для нового домена `beszel.example.com` и пропишите путь в `nginx.conf` и `docker-compose.yml` в `/opt/remnawave`.
    :::

    ```nginx title="nginx.conf" "yourdomain.com"
    upstream beszel {
        server 127.0.0.1:8090;
    }

    server {
        server_name beszel.yourdomain.com;
        listen 443 ssl;
        http2 on;

        ssl_certificate "/etc/nginx/ssl/yourdomain.com/fullchain.pem";
        ssl_certificate_key "/etc/nginx/ssl/yourdomain.com/privkey.pem";
        ssl_trusted_certificate "/etc/nginx/ssl/yourdomain.com/fullchain.pem";

        location / {
            proxy_http_version 1.1;
            proxy_pass http://beszel;
            proxy_set_header Host $host;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection $connection_upgrade;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Host $host;
            proxy_set_header X-Forwarded-Port $server_port;
            proxy_send_timeout 60s;
            proxy_read_timeout 60s;
        }
    }
    ```

    Перезапускаем nginx:

    ```bash
    cd /opt/remnawave && docker compose down remnawave-nginx && docker compose up -d remnawave-nginx && docker compose logs -f remnawave-nginx
    ```

    </TabItem>
    <TabItem label="Caddy">

    ```bash
    cd /opt/remnawave && nano Caddyfile
    ```

    Добавляем в конец файла сайт Beszel:

    ```caddyfile title="Caddyfile" "yourdomain.com"
    beszel.yourdomain.com {
        reverse_proxy 127.0.0.1:8090
    }
    ```

    Сертификат на этот домен Caddy получит сам.

    Перезапускаем Caddy:

    ```bash
    cd /opt/remnawave && docker compose restart remnawave-caddy
    ```

    </TabItem>
    </Tabs>

</Steps>

Не забудьте создать DNS-запись `beszel.example.com`, указывающую на сервер хаба.

## Добавление агента

<Steps>

1. Нажимаем `Add System`.

2. Выбираем способ подключения `Binary`.

3. Заполняем имя агента и указываем IP-адрес сервера ноды Remnawave. Порт можно оставить стандартный (45876).

4. Нажимаем `Copy Linux command` и получаем команду установки агента.

5. Переходим на сервер ноды и выполняем скопированную команду:

    ```bash
    curl -sL https://get.beszel.dev -o /tmp/install-agent.sh && chmod +x /tmp/install-agent.sh && /tmp/install-agent.sh -p 45876 -k "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIPW2NUPqCB4pq8oOgEFB9Luqe6oWjEy4bkQV3qcXo3qt" -t "8c9e7262-ced0-4162-bc49-4c985162c22f" -url "https://beszel.example.com"
    ```

6. Агент установлен:

    ![Install Agent](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/beszel/install_agent_beszel.png)

</Steps>

## Файрвол на сервере ноды

Агент сам инициирует подключение к хабу, но слушающий порт 45876 на ноде должен быть доступен хабу, и только ему.

<Steps>

1. Откройте порт 45876 (TCP) только для IP-адреса сервера хаба (замените `100.88.38.121` на актуальный адрес, например адрес в сети NetBird):

    ```bash
    ufw allow from 100.88.38.121 to any port 45876 proto tcp
    ```

2. Перезагрузите файрвол:

    ```bash
    ufw reload
    ```

3. Подождите пару минут, пока агент подключится к хабу:

    ![Host System](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/beszel/host_system_beszel.png)

</Steps>

## Уведомления в Telegram

<Steps>

1. Откройте `https://beszel.example.com` и войдите с логином и паролем администратора.

2. Перейдите в раздел `Settings`:

    ![Beszel Settings](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/beszel/beszel_settings.png)

3. Нажмите `Notification`:

    ![Beszel Notifications](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/beszel/beszel_notifications.png)

4. В поле Webhook / Push notifications вставьте ссылку вида:

    ```bash title="Webhook / Push notifications" "8266662524:AAHruriu0cLDEOlMgfgyrtbn7mJb6Cp4aY" "1465650656"
    telegram://8266662524:AAHruriu0cLDEOlMgfgyrtbn7mJb6Cp4aY@telegram?chats=1465650656
    ```

    `8266662524:AAHruriu0cLDEOlMgfgyrtbn7mJb6Cp4aY` это токен вашего бота.

    `1465650656` это ID чата, куда приходят уведомления.

5. Нажмите `Save Settings`.

</Steps>
