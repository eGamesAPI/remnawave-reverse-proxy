Это руководство поможет изменить текущий домен панели Remnawave (например, `olddomain.com`) на новый (например, `newdomain.com`): выпустить SSL-сертификат, обновить конфигурационные файлы и перенести адреса внутри панели. Если панель работает вместе с нодой, в конце есть дополнительные шаги.

:::danger[Перед началом]
Добавьте A-запись для нового домена, указывающую на этот сервер, и оставьте её в режиме **DNS only**: с включённым прокси Cloudflare (оранжевая галка) выпуск сертификата не пройдёт.
:::

## Шаг 1. Сертификат для нового домена

Сертификат выпускается модулем скрипта: вручную через certbot ничего делать не нужно.

<Steps>

1. Запустите меню скрипта командой `remnawave_reverse` (или коротким алиасом `rr`):

    ```bash
    remnawave_reverse
    ```

## Шаг 2. Конфигурация

Выберите свой вариант установки: списки файлов совпадают, но конфигурации отличаются.

<Tabs>
<TabItem label="Только панель">

<Steps>

1. Откройте файл `.env` для редактирования:

    ```bash
    nano /opt/remnawave/.env
    ```

2. Найдите строку с текущим доменом и замените её на новый:

    ```bash title=".env" "newdomain.com"
    FRONT_END_DOMAIN=newdomain.com
    ```

3. Откройте файл `docker-compose.yml`:

    ```bash
    nano /opt/remnawave/docker-compose.yml
    ```

4. Найдите сервис `remnawave-nginx` и обновите пути к сертификатам, заменив `olddomain.com` на `newdomain.com`:

    ```yaml title="docker-compose.yml" "newdomain.com"
    remnawave-nginx:
    image: nginx:1.28
    container_name: remnawave-nginx
    hostname: remnawave-nginx
    restart: always
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - /etc/letsencrypt/live/newdomain.com/fullchain.pem:/etc/nginx/ssl/newdomain.com/fullchain.pem:ro
      - /etc/letsencrypt/live/newdomain.com/privkey.pem:/etc/nginx/ssl/newdomain.com/privkey.pem:ro
    network_mode: host
    depends_on:
      - remnawave
      - remnawave-subscription-page
    logging:
      driver: 'json-file'
      options:
        max-size: '30m'
        max-file: '5'
    ```

5. Откройте файл nginx.conf:

    ```bash
    nano /opt/remnawave/nginx.conf
    ```

6. Найдите блок server и замените `olddomain.com` на `newdomain.com`:

    ```nginx title="nginx.conf" "newdomain.com"
    server {
        server_name newdomain.com;
        listen 443 ssl;
        http2 on;

        ssl_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";
        ssl_certificate_key "/etc/nginx/ssl/newdomain.com/privkey.pem";
        ssl_trusted_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";

        add_header Set-Cookie $set_cookie_header;

        location / {
            if ($authorized = 0) {
                return 444;
            }
            proxy_http_version 1.1;
            proxy_pass http://remnawave;
            proxy_set_header Host $host;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection $connection_upgrade;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Host $host;
            proxy_set_header X-Forwarded-Port $server_port;
            proxy_send_timeout 60s;
            proxy_read_timeout 60s;
        }
    }
    ```

7. Перезапустите сервисы, чтобы применить изменения:

    ```bash
    cd /opt/remnawave && docker compose down && docker compose up -d
    ```

</Steps>

<TabItem label="Панель + нода">

<Steps>

1. Откройте файл `.env` для редактирования:

    ```bash
    nano /opt/remnawave/.env
    ```

2. Найдите строку с текущим доменом и замените её на новый:

    ```bash title=".env" "newdomain.com"
    FRONT_END_DOMAIN=newdomain.com
    ```

3. Откройте файл `docker-compose.yml`:

    ```bash
    nano /opt/remnawave/docker-compose.yml
    ```

4. Найдите сервис `remnawave-nginx` и обновите пути к сертификатам, заменив `olddomain.com` на `newdomain.com`:

    ```yaml title="docker-compose.yml" "newdomain.com"
    remnawave-nginx:
    image: nginx:1.28
    container_name: remnawave-nginx
    hostname: remnawave-nginx
    network_mode: host
    restart: always
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
      - /etc/letsencrypt/live/newdomain.com/fullchain.pem:/etc/nginx/ssl/newdomain.com/fullchain.pem:ro
      - /etc/letsencrypt/live/newdomain.com/privkey.pem:/etc/nginx/ssl/newdomain.com/privkey.pem:ro
      - /dev/shm:/dev/shm:rw
      - /var/www/html:/var/www/html:ro
    command: sh -c 'rm -f /dev/shm/nginx.sock && nginx -g "daemon off;"'
    depends_on:
      - remnawave
      - remnawave-subscription-page
    logging:
      driver: 'json-file'
      options:
        max-size: '30m'
        max-file: '5'
    ```

5. Откройте файл nginx.conf:

    ```bash
    nano /opt/remnawave/nginx.conf
    ```

6. Найдите блок панели server и замените `olddomain.com` на `newdomain.com`:

    ```nginx title="nginx.conf" "newdomain.com"
    server {
        server_name newdomain.com;
        listen unix:/dev/shm/nginx.sock ssl proxy_protocol;
        http2 on;

        ssl_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";
        ssl_certificate_key "/etc/nginx/ssl/newdomain.com/privkey.pem";
        ssl_trusted_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";

        add_header Set-Cookie $set_cookie_header;

        location / {
            error_page 418 = @unauthorized;
            recursive_error_pages on;
            if ($authorized = 0) {
                return 418;
            }
            proxy_http_version 1.1;
            proxy_pass http://remnawave;
            proxy_set_header Host $host;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection $connection_upgrade;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Host $host;
            proxy_set_header X-Forwarded-Port $server_port;
            proxy_send_timeout 60s;
            proxy_read_timeout 60s;
        }

        location @unauthorized {
            root /var/www/html;
            index index.html;
        }
    }
    ```

7. Найдите блок ноды server и замените `olddomain.com` на `newdomain.com`:

    ```nginx title="nginx.conf" "newdomain.com"
    server {
        server_name newdomain.com;
        listen unix:/dev/shm/nginx.sock ssl proxy_protocol;
        http2 on;

        ssl_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";
        ssl_certificate_key "/etc/nginx/ssl/newdomain.com/privkey.pem";
        ssl_trusted_certificate "/etc/nginx/ssl/newdomain.com/fullchain.pem";

        root /var/www/html;
        index index.html;
    }
    ```

8. Откройте панель по защищённому порту: запустите `remnawave_reverse`, выберите пункт `3` (`Управление панелью/нодой`), затем пункт `6` («Доступ к панели через порт 8443», появляется только в связке панель + нода) и перейдите в браузере по адресу, который выдаст скрипт.

9. Внутри панели перенесите адреса на новый домен:

    - **Ноды → Управление** → выберите вашу ноду (Steal) → измените поле **Адрес** на `172.30.0.1` → **Сохранить**.

      <div style={{ display: 'flex', justifyContent: 'center' }}>
        <img
          src="https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/ru/remnawave_edit_node.png"
          alt="Address"
          style={{ maxWidth: '60%' }}
        />
      </div>

    - **Хосты → ваш хост** → в поле **Адрес** введите `newdomain.com` → **Сохранить**.
    - **Профили → ваш профиль (StealConfig)** → измените `serverNames` на `newdomain.com` → **Сохранить**.

10. Закройте доступ к порту 8443: `remnawave_reverse` → пункт `3` → пункт `6`.

11. Перезапустите сервисы:

    ```bash
    cd /opt/remnawave && docker compose down && docker compose up -d
    ```

</Steps>

## Проверка результата

<Steps>

1. Откройте браузер и перейдите на новый домен (не забывая про секретную ссылку с куками):

    ```bash "newdomain.com" "zIdejKtN" "MWbLrRzx"
    https://newdomain.com/auth/login?zIdejKtN=MWbLrRzx
    ```

2. Убедитесь, что панель Remnawave загружается корректно и сертификат SSL работает.

3. Если возникают ошибки, проверьте логи:

    ```bash
    cd /opt/remnawave && docker compose logs -f
    ```

4. Если панель не открывается, убедитесь, что DNS-записи для `newdomain.com` обновлены и указывают на ваш сервер.

</Steps>

:::tip[После замены]
Старый каталог сертификатов (`/etc/letsencrypt/live/olddomain.com`) можно удалить: продление теперь настроено только для нового домена. Домен страницы подписки (если она у вас есть) живёт отдельно и при необходимости меняется по той же схеме: своей A-записью, своим сертификатом и своим `.env` в `/opt/subscription`.
:::
