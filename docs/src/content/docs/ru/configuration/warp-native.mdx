Модуль `WARP Native` поднимает Cloudflare WARP на сервере в нативном режиме, то есть как обычный сетевой интерфейс WireGuard: профиль генерирует инструмент wgcf, а официальный клиент Cloudflare (приложение 1.1.1.1 или warp-cli) не нужен. Через этот интерфейс нода отправляет в WARP только выбранные домены, остальной трафик идёт напрямую.

## Что такое Cloudflare WARP?

`Cloudflare Warp` перенаправляет интернет-трафик через серверы Cloudflare:

- **Шифрование**: канал между сервером и Cloudflare работает по WireGuard, данные защищены на этом участке пути.
- **Другой адрес**: сайты видят адрес Cloudflare, а не адрес вашего сервера. Именно это проверяют сервисы whoer.net и 2ip.io из примеров ниже.
- **Маршрут через сеть Cloudflare**: трафик идёт по магистралям глобальной сети Cloudflare.

## Как это работает

<WarpDiagram lang="ru" />

Модуль на сервере панели добавляет в конфигурационный профиль ноды исходящий блок `warp-out` и правило маршрутизации с выделенными доменами. Нода направляет через интерфейс `warp` трафик только этих доменов, всё остальное уходит напрямую, а сайты видят адрес Cloudflare, а не адрес сервера.

### Установка Warp Native

:::danger[Важно]
Установка Warp Native производится только на сервере, на котором установлена нода Remnawave.
:::

<Steps>

1. Выберите пункт `Установить WARP Native`

    <Terminal title="root@server: ~" lines={[
      { kind: 'title', text: 'WARP Native' },
      { kind: 'dim', text: ' Подробности в wiki: https://wiki.egam.es/ru/configuration/warp-native' },
      { kind: 'plain' },
      { kind: 'item', num: '1.', text: 'Установить WARP Native', pick: true },
      { kind: 'item', num: '2.', text: 'Удалить WARP Native' },
      { kind: 'plain' },
      { kind: 'item', num: '3.', text: 'Добавить WARP-настройки в конфигурацию ноды' },
      { kind: 'item', num: '4.', text: 'Удалить WARP-настройки из конфигурации ноды' },
      { kind: 'plain' },
      { kind: 'item', num: '0.', text: 'Выход' },
      { kind: 'plain' },
      { kind: 'input', text: 'Выберите действие (0-4):' },
    ]} />

2. Скрипт скачает и запустит установщик wgcf: перед запуском он проверяется по контрольным суммам двух независимых источников, при несовпадении запуск отменяется.

</Steps>

### Добавление WARP-настроек

:::danger[Важно]
Запускать только на сервере, на котором установлена панель Remnawave.
:::

<Steps>

1. Выберите пункт `Добавить WARP-настройки в конфигурацию ноды` и подтвердите, что вы на сервере панели:

      { kind: 'input', text: '(y/n): ', answer: 'y' },
    ]} />

2. Затем выберите, в конфигурацию какой ноды добавить WARP-настройки:

    <Terminal title="root@server: ~" lines={[
      { kind: 'title', text: 'На какую ноду добавить WARP-настройки?' },

    <Terminal title="root@server: ~" lines={[

    ]} />

</Steps>

Если WARP уже настроен, модуль предупредит: «warp-out уже существует в outbounds.», настройка не задваивается.

В секцию вашего конфигурационного профиля ноды, добавляются следующие блоки:

export const exampleCode = `{
  "tag": "warp-out",
  "protocol": "freedom",
  "settings": {
    "domainStrategy": "UseIP"
  },
  "streamSettings": {
    "sockopt": {
      "interface": "warp",
      "tcpFastOpen": true
    }
  }
}`;
export const fileName = 'outbound';

<Code code={exampleCode} lang="json" title={fileName} />

export const fileName2 = 'routing rule';

### Удаление WARP-настроек

Пункт `Удалить WARP-настройки из конфигурации ноды` спрашивает ту же ноду и убирает добавленное:

<Terminal title="root@server: ~" lines={[
  { kind: 'title', text: 'На какой ноде удалить WARP-настройки?' },
  { kind: 'plain' },
  { kind: 'item', num: '1.', text: 'Default-Profile ', warn: '(de-fra-01)' },
  { kind: 'plain' },
  { kind: 'input', text: 'Выберите действие:' },
  { kind: 'plain' },
  { kind: 'ok', text: 'Удален warp-out из outbounds' },
  { kind: 'ok', text: 'Удален warp rule из routing rules' },
]} />

Если блоков в профиле уже нет, модуль скажет об этом прямо: «warp-out не найден в outbounds». Сам WireGuard-интерфейс удаляется пунктом `Удалить WARP Native`, после него модуль ответит «WARP успешно удалён».
