Скрипт ставит панель Remnawave, ноду и обратный прокси на NGINX и Xray одной командой. Xray работает прямо на порту 443 и передаёт трафик NGINX через Unix-сокет: без лишних TCP-звеньев соединения получаются быстрее и надёжнее.

:::note[Важно]
Скрипт работает на Debian и Ubuntu, протестирован на виртуализации KVM. Нужны собственный домен и root на свежеустановленной системе. Подробности собраны на странице [Обязательные требования](/ru/installation/requirements/).
:::

## Защита доступа к панели

При установке скрипт спрашивает, как защитить панель. По умолчанию это секретная ссылка:

```text "https://panel.example.com/auth/login?<SECRET_KEY>=<SECRET_KEY>"
https://panel.example.com/auth/login?<SECRET_KEY>=<SECRET_KEY>
```

Ссылка ставит в браузере cookie, и без правильной пары панель выглядит пустой страницей. Два других варианта закрывают панель отдельной страницей входа:
