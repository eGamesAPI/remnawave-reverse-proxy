## Установка Node.js и git

Node.js с npm нужны для сборки документации: скачайте их с [официального сайта Node.js](https://nodejs.org/en/download/). Инструкции по установке git есть на [git-scm.com](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git).

## Клонирование и запуск

<Steps>

1. Склонируйте репозиторий:

    ```bash
    git clone https://github.com/eGamesAPI/remnawave-reverse-proxy
    ```

2. Перейдите в директорию документации и установите зависимости:

    ```bash
    cd remnawave-reverse-proxy/docs
    npm install
    ```

3. Запустите dev-сервер:

    ```bash
    npm run dev
    ```

    Документация откроется на `http://localhost:4321`, изменения подхватываются на лету.

</Steps>

## Где что лежит

Английские страницы лежат в `src/content/docs/`, русские в `src/content/docs/ru/` с теми же путями. Меняя страницу, проверьте её парную версию на другом языке.

<FileTree>

- **docs** корневая директория документации
    - public/
    - src
        - assets/
            - en/
            - ru/
        - components/
        - **content/docs** корневая (en) директория документации
            - index.mdx
            - **ru/** русские страницы, те же пути
                - index.mdx
        - styles/
        - content.config.ts
- astro.config.mjs
- package.json
- tsconfig.json

</FileTree>

Starlight ищет файлы `.md` и `.mdx` в `src/content/docs/`: каждый файл становится страницей по своему пути. Изображения складываются в `src/assets/` и встраиваются относительной ссылкой, статические файлы вроде фавиконов живут в `public/`.

## Команды

Все команды выполняются из директории `docs`:

| Команда                   | Действие                                         |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Устанавливает зависимости                        |
| `npm run dev`             | Запускает локальный сервер на `localhost:4321`   |
| `npm run build`           | Собирает сайт в `./dist/`                        |
| `npm run preview`         | Показывает сборку локально перед деплоем         |
| `npm run astro ...`       | Выполняет команды CLI, например `astro check`    |

## Отправка изменений

<Steps>

1. Создайте ветку под правку:

    ```bash
    git checkout -b my-change
    ```

2. Внесите изменения и закоммитьте:

    ```bash
    git add . && git commit -m "docs: моя правка"
    ```

3. Отправьте ветку и откройте pull request в [репозитории](https://github.com/eGamesAPI/remnawave-reverse-proxy/pulls):

    ```bash
    git push -u origin my-change
    ```

</Steps>

После проверки мы вольём правку, и она появится на [wiki.egam.es](https://wiki.egam.es). Вопросы можно задать в [Telegram-чате](https://t.me/remnawave_reverse).
