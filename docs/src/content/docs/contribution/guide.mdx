## Installing Node.js and git

Node.js with npm are needed to build the documentation: download them from the [official Node.js website](https://nodejs.org/en/download/). Git installation instructions live on [git-scm.com](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git).

## Cloning and running

<Steps>

1. Clone the repository:

    ```bash
    git clone https://github.com/eGamesAPI/remnawave-reverse-proxy
    ```

2. Go to the documentation directory and install the dependencies:

    ```bash
    cd remnawave-reverse-proxy/docs
    npm install
    ```

3. Start the dev server:

    ```bash
    npm run dev
    ```

    The documentation opens at `http://localhost:4321`; changes are picked up on the fly.

</Steps>

## Where everything lives

English pages live in `src/content/docs/`, Russian ones in `src/content/docs/ru/` under the same paths. When editing a page, check its counterpart in the other language.

<FileTree>

- **docs** documentation root directory
    - public/
    - src
        - assets/
            - en/
            - ru/
        - components/
        - **content/docs** root (en) documentation files
            - index.mdx
            - **ru/** Russian pages, same paths
                - index.mdx
        - styles/
        - content.config.ts
- astro.config.mjs
- package.json
- tsconfig.json

</FileTree>

Starlight looks for `.md` and `.mdx` files in `src/content/docs/`: every file becomes a page at its own path. Images go into `src/assets/` and are embedded with a relative link; static files like favicons live in `public/`.

## Commands

All commands run from the `docs` directory:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts a local server at `localhost:4321`        |
| `npm run build`           | Builds the site into `./dist/`                   |
| `npm run preview`         | Shows the build locally before deploying         |
| `npm run astro ...`       | Runs CLI commands, for example `astro check`     |

## Sending changes

<Steps>

1. Create a branch for your change:

    ```bash
    git checkout -b my-change
    ```

2. Make the changes and commit them:

    ```bash
    git add . && git commit -m "docs: my change"
    ```

3. Push the branch and open a pull request in the [repository](https://github.com/eGamesAPI/remnawave-reverse-proxy/pulls):

    ```bash
    git push -u origin my-change
    ```

</Steps>

After review we will merge the change, and it will appear on [wiki.egam.es](https://wiki.egam.es). Questions are welcome in the [Telegram chat](https://t.me/remnawave_reverse).
