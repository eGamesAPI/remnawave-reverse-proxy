## Running the script

:::danger[Important]
The script must be run as **root**.
:::

Run this command on your server:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[If GitHub is unreachable]
Run the installer from the jsDelivr mirror:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Installing the panel

### What the installer does

1. **Checks the server before starting**: the panel is not installed yet, port 443 is free.
2. **Asks for one domain**: the panel's. It is validated and its DNS record is checked.
3. **Generates every secret itself**: the superadmin login and password, the `name=value` pair for the secret login link, a separate metrics pair and `APP_SECRET`. Nothing to invent or remember: everything is shown at the end.
4. **Deploys the services into `/opt/remnawave`**: the PostgreSQL database, the Valkey cache, the RemnaWave panel and an nginx reverse proxy in front of it.
5. **Issues a Let's Encrypt certificate** for the panel domain using the method you pick (DNS API, ACME HTTP-01 or your own) and sets up renewal.
6. **Configures the panel through its API**: registers the superadmin and prepares everything for connecting nodes.
7. **Restarts the stack cleanly** (`down` + `up`): if something did not come up, the error cannot hide behind the green banner.

## Updating the script

Make sure the script is up to date before you do anything else with it.

1. Open the script menu with the `remnawave_reverse` command (or the short alias `rr`) and select item `12`, `Check for updates script`. When an update is already found, the item lights up red and reads `Update script`:
