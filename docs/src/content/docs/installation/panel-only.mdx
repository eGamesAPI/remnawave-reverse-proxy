## Running the script

:::danger[Warning]
Script must be run as **root**.
:::

Enter the command on your server:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

## Install only the panel

<Steps>

1. Select `Install Remnawave components`

    ![Main menu RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/main_menu.webp)

2. Then select `Install only the panel`

    ![Install panel RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/install_panel.webp)

3. Select the web server for the panel. Both options are fully supported by the script:

    - **Nginx** — the classic setup used in all previous versions.
    - **Caddy** — automatic HTTPS certificates out of the box.

    ![Select web server](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/webserver_select.webp)

4. Choose the panel protection method:

    - `Cookie protection (default)` — the panel is protected by a secret link, as in previous versions.
    - With **Nginx**: `Login page (TinyAuth)` — an additional login page in front of the panel.
    - With **Caddy**: `Login page with MFA` — a login portal with multi-factor authentication.

5. After the process is complete, the script will provide all the necessary login information.

    ![Menu panel end RU](https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/docs/src/assets/en/menu_panel_end.webp)

</Steps>

:::danger[Warning]
After the installation is complete, the script will display a unique URL for logging into the control panel.  
**Be sure to save this URL.** It contains the secret key needed for access.

Example login link:
```
https://p.example.com/auth/login?SECRET_KEY=SECRET_KEY
```
Without this URL, **you will not be able** to log into the panel.
:::

## Updating the script

Make sure to update the script before running things in it. You can do this by selecting `Check for updates script` in the script menu or by viewing the GitHub repository for updates.
