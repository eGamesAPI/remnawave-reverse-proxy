## Running the script

:::danger[Important]
The script must be run as **root**, and on the server that will host the RemnaWave node.
:::

Run this command on your server:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[If GitHub is unreachable]
Run the installer from the jsDelivr mirror:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Installing the node

### What the installer does

1. **Checks the server before starting**: the node is not installed yet, port 443 is free.
2. **Asks for three things**: the node's selfsteal domain (the address from its card in the panel), the panel's IP address and the node's Secret Key, pasted as a multi-line block and confirmed.
3. **Issues a certificate** for the node domain (DNS API, ACME or your own) and sets up renewal.
4. **Deploys the services into `/opt/remnanode`**: the `remnanode` node container and nginx behind a Unix socket, the same scheme as the panel's: Xray owns 443 and hands traffic to nginx over the socket.
5. **Opens port 2222 in the firewall for the panel's IP only**: the panel can reach the node, everyone else cannot.
6. **Installs the camouflage site**: a random template of an ordinary website on the node's domain.
7. **Starts and verifies**: checks `https://domain` up to 5 times with a 15-second pause until the node answers.

## Updating the script

Make sure the script is up to date before you do anything else with it.

1. Open the script menu with the `remnawave_reverse` command (or the short alias `rr`) and select item `12`, `Check for updates script`. When an update is already found, the item lights up red and reads `Update script`:
