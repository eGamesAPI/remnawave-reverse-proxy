:::tip[If your hardware is weaker]
`Remnawave` can run on smaller machines, but it is not recommended: some background processes are resource-hungry. `Remnawave Node` itself is modest, but Xray-core can eat a lot of CPU and RAM under load.
:::

## What to prepare

- **Root access** on the server and a fresh OS install: tested on KVM virtualization.
- **Ports 80 and 443 free**: the web server and Xray take them. The node's port 2222 is opened in the firewall by the script itself, for the panel only.
- **Three domains or subdomains**: the panel, the subscription page and the camouflage site (selfsteal). The A record for a new node can be created by the script itself via the Cloudflare, Gcore or Bunny.net API.

## Domain setup

The script issues SSL certificates in two ways:

- **Cloudflare**: DNS managed through the API, records are created automatically with a token;
- **ACME**: direct integration with the hosting provider, no API key.

### DNS configuration examples

#### Single server installation (panel + node together)

| Record Type | Name              | Value            | Proxy Status |
|-------------|-------------------|------------------|--------------|
| A           | example.com       | your_server_ip   | DNS only     |
| CNAME       | panel.example.com | example.com      | DNS only     |
| CNAME       | sub.example.com   | example.com      | DNS only     |
| CNAME       | node.example.com  | example.com      | DNS only     |

:::tip
The `node.example.com` record is optional for SelfSteal: the root domain `example.com` works too.
:::

#### Distributed installation (panel and node on different servers)

| Record Type | Name              | Value                | Proxy Status |
|-------------|-------------------|----------------------|--------------|
| A           | example.com       | panel_server_ip      | DNS only     |
| CNAME       | panel.example.com | example.com          | DNS only     |
| CNAME       | sub.example.com   | example.com          | DNS only     |
| A           | node.example.com  | node_server_ip       | DNS only     |

## When everything is ready

Run the installer on the server as root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[If GitHub is unreachable]
Run the installer from the jsDelivr mirror:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

After the first install the script adds itself the short alias `rr`: the menu opens with the `remnawave_reverse` command or just `rr`.
