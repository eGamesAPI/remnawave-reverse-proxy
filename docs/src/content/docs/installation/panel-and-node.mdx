## Running the script

:::danger[Important]
The script must be run as **root**.
:::

Run this command on your server:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/eGamesAPI/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

:::danger[If GitHub is unreachable]
Run the installer from the jsDelivr mirror:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/eGamesAPI/remnawave-reverse-proxy@main/install_remnawave.sh)
```
:::

## Installing the panel and node

:::danger[Important]
This installation method is not recommended for production use because it is absent from the official RemnaWave documentation.

For best results and stability, choose the [`Panel only`](https://wiki.egam.es/installation/panel-only/) or [`Node only`](https://wiki.egam.es/installation/node-only/) method depending on your needs.
:::

### What the installer does

While you answer the questions, the script does all the work itself:

1. **Checks the server before starting**: port 443 is free, neither the panel nor the node is running, so the install never lands on top of a live setup.
2. **Asks for three domains**: the panel, the subscription page and the camouflage site (selfsteal). Each domain is validated, its DNS record is checked, and all three must be different.
3. **Generates every secret itself**: the superadmin login and password, the `name=value` pair for the secret login link, a separate metrics login and password, and `APP_SECRET`. Nothing to invent or remember: everything is shown at the end.
4. **Deploys the services into `/opt/remnawave`**: the PostgreSQL database, the Valkey cache, the RemnaWave panel, a reverse proxy behind a Unix socket, the subscription page and the `remnanode` node. The node's Xray owns port 443 and hands web traffic to the proxy over the socket, with no extra TCP hops.
5. **Issues Let's Encrypt certificates** for all domains at once, using the method you pick (DNS API, ACME HTTP-01 or your own), and sets up renewal.
6. **Installs the camouflage site**: a random template of an ordinary website on the selfsteal domain, so the node does not stand out from regular traffic.
7. **Configures the panel through its API**: registers the superadmin, creates the StealConfig profile, the node and the host, binds them to the default squad and issues a token for the subscription page.
8. **Restarts the stack cleanly** (`down` + `up`): if something did not come up, the error cannot hide behind the green "installation complete" banner.
