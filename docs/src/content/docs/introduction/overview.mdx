The script installs the Remnawave panel, a node and a reverse proxy on NGINX and Xray in one command. Xray runs directly on port 443 and hands traffic to NGINX through a Unix socket: with no extra TCP hops, connections come out faster and more reliable.

:::note[Important]
The script works on Debian and Ubuntu and has been tested on KVM virtualization. You need your own domain and root on a freshly installed system. The details are collected on the [Requirements](/installation/requirements/) page.
:::

## Panel access protection

At installation the script asks how to protect the panel. The default is a secret link:

```text "https://panel.example.com/auth/login?<SECRET_KEY>=<SECRET_KEY>"
https://panel.example.com/auth/login?<SECRET_KEY>=<SECRET_KEY>
```

The link sets a cookie in the browser, and without the correct pair the panel looks like a blank page. The two other options put a login page in front of the panel:
